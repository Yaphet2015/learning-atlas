# Studyboard 使用指南

[返回 README](../README.md)

## 连接真实 AI

按 `⌘.`（其他系统 `Ctrl+.`，也可用 `⌘,`、`⌘K → 设置` 或 macOS 应用菜单「Settings…」）打开设置页，在「AI 服务」里填写 API 地址、模型 ID 和你自己的 API 密钥。设置页还有外观（深浅色）、快捷键列表和关于/许可。

- 默认使用 OpenAI，模型 `gpt-4o-mini`，地址 `https://api.openai.com/v1`
- 支持 OpenAI-compatible Chat Completions 的 HTTPS 服务，兼容性取决于服务商
- 桌面版只需输入一次：密钥由主进程用 Electron `safeStorage`（macOS 上由钥匙串保管加密密钥）加密后存到 `ai/key.json`，磁盘上只有密文；界面只显示遮盖后的末四位（如 `sk-••••a1b2`），可「更换」或「清除」
- 如果系统钥匙串不可用（例如 Linux 没有密钥环），设置页会明确提示，此时密钥只保留到退出应用，不会以明文写入磁盘
- 浏览器预览不接收、不保存密钥
- 修改到另一个 API 地址时，必须显式提供该地址的密钥，不会暗中复用旧服务商的密钥
- 也可以在启动应用的进程环境中显式设置 `OPENAI_API_KEY`；环境密钥只用于官方 OpenAI 地址
- 设置保存时不会调用模型，也不代表连接已测试。主动提问、点击「测试连接」，以及已配置 AI 后触发卡片悬停或选中提示时会请求服务商，可能产生 API 费用。卡片提示按相关状态缓存；状态未变时复用已有结果。「测试连接」发送一次极短的请求，不会保存当前表单配置

发送问题时，所选服务商会收到：该问题、当前批注的对话历史、原始主题、选定/关联概念或关系、附近分支，以及整张白板的精简提纲。其他白板和其他批注的对话不会自动拼接。实际引用在界面中可查看。

真实 AI 运行时精确锁定以下实验性 API：

- `@earendil-works/pi-durable@1.3.0`
- `@earendil-works/pi-ai@1.3.0`
- `@earendil-works/chord@1.3.0`

没有 faux-provider 运行时回退，没有 Shell、文件、浏览器或任意代码执行工具。单元测试中的离线 provider transport 仅用于测试，不能从应用设置启用。

## 保存与恢复

桌面数据保存在 Electron 的 `userData` 目录，macOS 通常为 `~/Library/Application Support/Studyboard/`。从旧名 Learning Atlas 升级时，首次启动会把 `~/Library/Application Support/Learning Atlas/` 里的 `boards/` 和 `ai/` 复制过来（仅当新目录还没有数据时；旧目录保留不删）：

- `boards/`：经过校验的 JSON 白板，串行原子写入
- `ai/`：按白板/批注隔离的 SQLite 对话数据库，真实 durable 历史

正常关闭会先要求界面保存当前白板，再关闭运行时。如果保存失败，关闭会被取消并提示。突然断电/强制结束进程仍可能丢失最后未提交的编辑。完整 AI 对话在 SQLite；白板只缓存最近 200 条消息，每条最多 32,000 字符。所有数据都是本地文件，不提供云同步或本地静态加密。

重新打开会恢复对话，但不会为了恢复旧请求而自动产生新的付费调用。之前未完成的请求保持暂停；在那张批注再次提问时，旧请求会被中止，新问题开始。原来的消息仍保留。

## 导出与共享

左侧边栏提供「导出当前画板」和「导入画板」。也可用 `⌘K` 搜索这两个操作。

- **学习数据（`.studyboard.json`）**：包含卡片、层级、连线、批注、理解进度、演练状态及完整对话。将文件发给别人，对方可在 Studyboard 中导入并继续学习。导入会创建新画板；AI 对话历史会恢复到独立 SQLite 数据库，后续提问可接着原来的历史继续。文件不包含 API 密钥或服务商配置。
- **Markdown（`.md`）**：按知识层级导出正文、理解进度、关系、演练记录、批注及完整对话，便于阅读和整理。内容中的 HTML、外部图片和链接以文字形式保留。
- **PNG（`.png`）**：导出整张知识图，包含屏幕外的卡片。超大地图会缩小到图片尺寸上限；截图使用系统字体。

数据文件最大为 64 MB。完整对话导出从数据库读取，不受画板 JSON 的最近 200 条消息缓存限制；正在回答的对话需完成或停止后再导出。批注的「更多操作 → 查看完整对话」可以阅读超过 200 条的历史。数据导入不触发 AI 请求；接收方继续提问时使用自己的 AI 配置。Markdown 和 PNG 用于阅读与展示，可重新导入的是学习数据文件。

网页预览支持相同的数据导入导出，完整历史保存在浏览器本地存储中，容量受浏览器限制。

## 快捷键

- `N`：放下自由批注
- `0`：查看全图
- `F`：走一遍
- `⌘N`：新白板
- `⌘\`（其他系统 `Ctrl+\`）：展开 / 收起左侧边栏
- `⌘Z`：撤销地图编辑
- `⌘S`：立即保存
- `⌘Enter`：发送批注问题
- `Esc`：关闭面板/对话框或取消选择
- `/`：问 AI（选中多张卡时，带着这几张一起问）
- 按住 `空格` 拖动：临时平移画布

知识画布：左侧边栏列出所有画布，支持搜索和新建。点击一项会切换整张画布及其对话上下文，并清除上一张画布的卡片选区和编辑状态。侧边栏可收起为图标栏；展开状态会保存在当前设备。单击卡片会在右侧显示该卡片的全文。

画布交互：选择工具下，在空白处按住左键拖出框选（碰到即选中）；`Shift`/`⌘`（Windows/Linux 为 `Ctrl`）点击卡片可加入或移出多选，按住修饰键框选会叠加到已有选择。平移不受影响：双指滚动、按住空格拖动、中键/右键拖动，或切到手形工具（`H`）。选中两张以上时顶部出现「已选 N 张卡 · 问 AI · 清除」，问 AI 会新开一段对话，把这些卡都作为上下文；对话里「参考 → 添加卡片」可以搜索整张白板，随时加入或移出卡片。

对话列表：在左侧边栏展开画布下的对话，点击一条即可打开对应的右侧抽屉，并定位关联卡片。可以从边栏「新对话」或卡片菜单「在这张卡上新开对话」另起一段；之后在这张卡上按 `/` 打开最近的一段。对话随白板一起保存（网页预览存在浏览器本地，桌面版存在白板文件和 SQLite 中），重新打开后仍可查看。

从节点圆点拖到另一个节点圆点可以新建关系；选中连线可以改标签。右键空白区域也可以放批注。拖动批注标题移动它。
